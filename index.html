ADSP-SC594 Fault Trace

Implemented fault and schedule tracing for CPU/OS faults, storing trace data in DDR3 memory for retrieval during subsequent boots.

Overview

Designed and implemented a complete fault tracing subsystem for the ADSP-SC594 Audio DSP. When a CPU or OS fault occurs, the system automatically captures the fault context, schedule trace, and a backtrace up to 4 levels deep. This data is stored in a dedicated DDR3 region that persists across reboots.

Key Contributions
  • Allocated dedicated memory sections in DDR3 via Linker Script modifications for persistent fault storage.
  • Built a capture mechanism that records CPU/OS fault details and the active task schedule trace at the moment of failure.
  • Implemented backtrace extraction (up to level 4) to pinpoint the exact call chain leading to the fault.
  • Developed boot-time retrieval logic that reads and displays the stored trace data from DDR3 on the next system startup.
  • Validated end-to-end by injecting faults and verifying correct data retrieval and integrity after reboot cycles.

Bootloader Optimization

Optimized the ADSP-SC594 boot process to run directly from SRAM, successfully enabling a secure boot architecture.

Overview

The ADSP-SC594 Audio DSP uses a two-stage boot process. The first-stage ROM bootloader loads an init code segment, which configures the on-board DDR, then the second-stage bootloader is loaded into DDR. This project eliminated the separate init code stage by integrating it directly into the second-stage bootloader, which is a critical prerequisite for implementing Secure Boot.

Key Contributions
  • Reverse-engineered the existing Linker Scripts to fully understand the memory layout and boot flow.
  • Merged the init code logic (DDR configuration) directly into the second-stage bootloader.
  • Rewrote the Linker Scripts to relocate the bootloader to execute entirely from SRAM before DDR is available.
  • Verified that the unified bootloader image correctly configures DDR and boots the application.
  • Performed hardware-level validation on the target ADSP-SC594 board.
  • Linker Scripts
  • SRAM
  • Secure Boot
